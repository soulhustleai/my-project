# CANVA TEXT OVERLAY SPECS — Covers #4, #8, #9
## 2-Minute Fix Per Cover

> **GLOBAL SETTINGS (same for all covers):**
> - Background: Upload MJ image as full-bleed background
> - Canvas size: 1200 x 1800px (2:3 ratio)
> - ALL text: Cinzel font (search "Cinzel" in Canva — it's free)
> - ALL text color: Gold #C9A033
> - Text effect: Add subtle drop shadow (black, 50% opacity, 2px offset)
> - If MJ rendered garbled text: Cover it with a black rectangle (#050505) first, then place clean text on top

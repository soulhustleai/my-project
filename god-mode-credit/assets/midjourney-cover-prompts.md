## IMPORTANT: How to Use These Prompts

1. Paste the prompt into Midjourney exactly as written
2. Generate 4 options (MJ default)
3. Pick your favorite and upscale (U1, U2, U3, or U4)
4. Download the high-res version
5. If the text isn't perfect (MJ sometimes misspells), use Canva or Photoshop to clean up ONLY the text — the design/background is done

> **Text tip:** Midjourney v6+ handles text much better than older versions. Use `--v 6.1` at the end of every prompt. If text still has issues, regenerate or fix in Canva (just the text layer, keep the background).

## TIPS FOR BEST RESULTS

1. **If text is misspelled:** Regenerate (MJ v6.1 is much better but not perfect). Or keep the design and replace ONLY the text in Canva.
2. **For variations:** Add `--chaos 20` to get more diverse options
3. **For more luxury feel:** Add "luxury editorial design, Vogue aesthetic, premium fintech brand" to any prompt
4. **To adjust gold tone:** Replace `#C9A033` description with "warm gold" or "rose gold" or "champagne gold"
5. **Resolution:** After upscaling in MJ, the images are print-ready for ebook covers
6. **Consistency:** Run all covers in the same MJ session for visual consistency across the brand

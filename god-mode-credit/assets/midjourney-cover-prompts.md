## IMPORTANT: How to Use These Prompts

**RECOMMENDED APPROACH (Most Reliable):**
1. Use **PLAN A** prompts first — these include text on the cover
2. If the text comes out garbled (common with 3+ text elements), use **PLAN B** — background-only prompts with NO text
3. For Plan B results, add ALL text in **Canva** using Cinzel font, gold color #C9A033
4. Generate 4 options → pick favorite → upscale (U1-U4) → download high-res

**MJ Pro Tips:**
- MJ does NOT read hex codes as colors. We use descriptive color language instead.
- `--no red blue purple green silver` prevents unwanted color bleeding
- Multi-line text (3+ elements) will often render incorrectly — Plan B exists for this reason
- Run all covers in the same session for visual consistency

## TIPS FOR BEST RESULTS

1. **Plan B is more reliable** for most covers — generate the background in MJ, add text in Canva for perfect typography
2. **Run all covers in one MJ session** for visual consistency
3. **For variations:** Add `--chaos 20` to get more diverse options
4. **For more luxury feel:** Replace `--style raw` with `--stylize 750`
5. **For metallic objects:** Adding "octane render quality" gets better metallic surfaces
6. **Resolution:** After upscaling in MJ, images are print-ready for ebook covers
7. **If MJ is unavailable:** These prompts work in DALL-E 3 and Adobe Firefly with minor adjustments (remove MJ-specific flags)

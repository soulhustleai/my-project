# APEX VSL SCRIPTS
## 60-Second Video Sales Letters — One per product

> Every script is pre-formatted for direct handoff to ElevenLabs. Voice profile: `ELEVENLABS_APEX_VOICE_ID`. Settings: Stability 55 / Clarity 85 / Style 20 / Boost ON. See `../voice-config.md` for full spec.
>
> **Format legend:** `[APEX — POSE: X]` tells the editor which static image to pull. `[BG: ...]` is the environment cue. `<break time="Xs" />` is SSML — ElevenLabs honors it. Line labels (COLD OPEN / REVEAL / VERDICT / CTA / SIGN-OFF) tell the editor the emotional beat.

## Production flow

1. Generate Apex voice via ElevenLabs using this script
2. Import voice track into video editor
3. Overlay: Apex static image (pose per line label) + throne room background (`apex-throne-room-wide-v1.png`)
4. B-roll: product cover + glowing gold particles + federal code typography flashes
5. Music: sub-bass drone + subtle gold chime accents only. NO melody.
6. CTA card at end: product name, price, storefront URL
7. Export: 9:16 (TikTok/Reels) and 1:1 (feed) versions
8. Name: `apex-vsl-<product-slug>-v1-<aspect>.mp4`

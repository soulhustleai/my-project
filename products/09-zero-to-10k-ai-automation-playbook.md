## TOOL 1: MAKE.COM
**Role: Connect Everything**
**Cost: Free tier (1,000 operations/month) | Core: $9/mo | Pro: $16/mo**

Make.com is a visual automation platform. You build "scenarios" — sequences of actions triggered by events.

Think of it as: IF [this happens] → THEN [do all of these things automatically].

### What It Does for You
- When someone buys on Payhip → automatically add them to ConvertKit with the right tag
- When you get a new Instagram follower → automatically send them a welcome DM
- When a form is filled out → create a Notion task AND send a welcome email AND notify you by SMS
- When you publish a video → automatically post to 5 platforms

### Your First 3 Scenarios

**Scenario 1: Payhip → ConvertKit Buyer Tag**
```
Trigger: Payhip webhook (new purchase)
Action 1: Add subscriber to ConvertKit
Action 2: Add tag "buyer-[product-name]"
Action 3: Trigger automation sequence for that product
Action 4: Send Twilio SMS to Edwin "New sale: $X from [product]"
```

**Scenario 2: New Lead Magnet Signup**
```
Trigger: ConvertKit new subscriber with tag "lead-magnet"
Action 1: Send welcome email (ConvertKit handles this)
Action 2: Add to Notion leads database
Action 3: Schedule follow-up reminder in Notion (Day 3, Day 7)
```

**Scenario 3: Content Publishing Alert**
```
Trigger: Buffer/Later.com webhook (post published)
Action 1: Log to Notion content calendar
Action 2: Create Notion task "Monitor engagement in 24 hours"
```

### How to Use It

## TOOL 5: OPUS CLIP
**Role: Video Repurposing**
**Cost: Starter: $15/mo | Pro: $29/mo**

Opus Clip takes one long video and automatically:
- Identifies the most engaging moments
- Creates 9:16 vertical clips (perfect for TikTok/Reels/Shorts)
- Adds captions automatically
- Adds "hook score" to help you pick winners

### The Content Multiplication Formula

**One 10-minute video → 10+ Reels/Shorts:**
1. Record or generate one 10-min educational video
2. Upload to Opus Clip
3. Opus identifies 10 clips automatically
4. Review, approve, export
5. Upload to Later.com for scheduling

**Content Sources for Opus Clip:**
- Long YouTube videos about credit/finance (react/commentary format)
- Your own educational content
- Podcast-style recordings (just audio + static image works in Opus Clip)

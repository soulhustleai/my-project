## WORKFLOW FOR EACH CEO

1. **Pull a reference clip** from the source candidates (YouTube audio → extract 3-10 sec with `yt-dlp` + `ffmpeg`)
2. **Save to repo:** `god-mode-credit/apex/voice-samples/references/<suggested-name>.wav`
3. **Upload to VoxCPM server:**
   ```bash
   curl -X POST -H "Authorization: Bearer $VOXCPM_API_KEY" \
        -F name=<suggested-name> \
        -F file=@god-mode-credit/apex/voice-samples/references/<suggested-name>.wav \
        $VOXCPM_URL/voices
   ```
4. **Update `ceo_brains`:**
   ```sql
   UPDATE ceo_brains SET
     voice_backend = 'voxcpm',
     voice_id = '<suggested-name>',
     voice_reference_url = 'https://raw.githubusercontent.com/soulhustleai/my-project/main/god-mode-credit/apex/voice-samples/references/<suggested-name>.wav',
     voice_status = 'live',
     updated_at = NOW()
   WHERE UPPER(name) = '<CEO_NAME>';
   ```
5. **Test via voice router:**
   ```python
   from voice_router import speak, refresh_registry
   refresh_registry()
   speak(ceo="aegis", text="This is AEGIS. Big brother energy. Ascend.")
   ```
6. **Mark validated** in the status table below
